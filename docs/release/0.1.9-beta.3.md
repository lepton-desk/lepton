The last beta of 0.1.9: Linux and Windows, and the API frozen from here to 0.1.9.

## Install

With Node 20+ and any of npm, pnpm, Yarn or Bun:

```bash
npm create lepton-app@beta
```

Without npm, download the `lepton` CLI below for your system, check it against its
`.sha256`, and put it on your `PATH`:

```bash
sha256sum -c lepton-0.1.9-beta.3-linux-x64.tar.gz.sha256
tar -xzf lepton-0.1.9-beta.3-linux-x64.tar.gz
```

On Windows, `Get-FileHash lepton-0.1.9-beta.3-windows-x64.zip` and compare it with the
`.sha256`. A project still needs Zig 0.16 or 0.17, and on Linux WPE WebKit 2.54+;
`lepton info` says what is missing.

## What's new

- **Your app's name in the title bar your page draws**: `info()` and `title()` in
  `@lepton-desk/api`.
- **Single instance and deep links** (`deepLinks`), **`fs.watch`**, **unlimited frames**
  for native apps.
- **Windows**: the native path on the GPU (Vulkan, Direct3D 11, OpenGL 3.3), your own title
  bar and native menus, notifications under the app's name, an MSI that replaces another
  build of the same version.
- **Linux**: the dock shows a WPE WebKit app's icon and name; Servo (experimental) has
  cursors, storage, cookies and top-level `await`.
- **Zig 0.16 and 0.17** both build Lepton.

0.1.9-beta.2 went out only in part, from Windows; everything since beta.1 arrives here.
Every change is in [`CHANGELOG.md`](https://github.com/lepton-desk/lepton/blob/trunk/CHANGELOG.md#019-beta3);
what to do in an existing app is on the site's
[Changes](https://lepton-desk.vercel.app/docs/changelog/) page.
